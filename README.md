# MSL Hand Gesture Recognition — Training Pipeline

Implements your pseudocode: MediaPipe landmark extraction → normalisation →
SVM / MLP / Random Forest training → evaluation → comparison report.

## Folder structure

```
msl_recognition_system/
├── data/
│   ├── raw/                     # <-- put your datasets here (see below)
│   │   ├── alphabet/            # A/ ... Z/
│   │   └── number/              # 0/ ... 10/
│   └── processed/
│       ├── landmarks_alphabet.csv   # generated by landmark_extraction.py
│       └── landmarks_number.csv
├── models/                      # hand_landmarker.task (auto-downloaded)
│   ├── alphabet/                # svm_model.pkl, mlp_model.pkl,
│   └── number/                  #   randomforest_model.pkl, label_encoder.pkl
├── results/
│   ├── alphabet/                # evaluation_results.json / .csv
│   └── number/
├── src/
│   ├── config.py                # all paths & settings in one place
│   ├── normalization.py         # translate + scale landmark normalisation
│   ├── hand_detector.py         # MediaPipe Tasks HandLandmarker factory
│   ├── landmark_extraction.py   # dataset -> feature CSV
│   └── train_models.py          # split, train, evaluate, save
├── app/
│   ├── app.py              # Streamlit entry point (sidebar + tab router)
│   ├── ui_helpers.py       # Shared rendering & input helpers
│   ├── inference.py        # Model loading, prediction, hand detection
│   └── tabs/
│       ├── reference.py    # Reference Library — browse sign images
│       ├── playground.py   # Playground — free prediction with confidence
│       ├── quiz.py         # Quiz — perform a sign, get proximity feedback
│       └── developer.py    # Developer Dashboard — 3-algorithm comparison
└── requirements.txt
```

## 1. Add your dataset

Alphabet and number are two independent classification tasks — each gets its
own dataset, model set and report:

```
data/raw/alphabet/
    A/   img001.jpg  img002.jpg ...
    B/   ...
    ...
    Z/

data/raw/number/
    0/   img001.jpg  img002.jpg ...
    1/   ...
    ...
    10/
```

(Class labels are taken from the subfolder names.)

## 2. Install dependencies

```bash
pip install -r requirements.txt
```

## 3. Extract landmarks

```bash
python -m src.landmark_extraction --mode all     # or: alphabet / number
```
Detects the hand in every image, pulls out 21 MediaPipe landmarks,
normalises them (wrist-centered, scale-invariant), flattens to a
63-value feature vector, and writes everything to
`data/processed/landmarks_<mode>.csv`.

> The first run downloads the MediaPipe `hand_landmarker.task` model
> (~8 MB) into `models/` automatically — needs internet once.

## 4. Train + evaluate all 3 algorithms

```bash
python -m src.train_models --mode all            # or: alphabet / number
```
Splits each mode's CSV 70/15/15 (train/val/test, stratified), trains SVM,
MLP and Random Forest, computes accuracy/precision/recall/F1/inference time
for each, saves the trained models to `models/<mode>/`, and writes the
comparison report to `results/<mode>/evaluation_results.json` and `.csv`.

## 5. Run the Streamlit app

```bash
streamlit run app/app.py
```

The sidebar controls recognition mode (Alphabet / Number), input source
(upload / snapshot / live camera), and a shared confidence threshold slider.

### Reference Library

Grid of reference images showing what each sign looks like (read from
`data/raw/`). Click a class to expand and see multiple samples. No model
involved — purely visual.

### Playground

Free exploration. Upload a photo, take a snapshot, or use the live camera.
All 3 algorithms (SVM, MLP, RandomForest) predict side by side with
confidence bars, top-5 "similar signs" charts, and an agreement badge.
Below the threshold the system says "not confident enough" instead of
forcing a labeled guess.

### Quiz

Pick a target class or let the system randomise one, then perform the
gesture. Instead of a flat correct/incorrect mark, each algorithm reports
how confident it is in the target class (proximity score). If the gesture
wasn't quite right, it shows what it actually resembled.

### Developer Dashboard

Same input flow and threshold slider, but adds a full comparison report:
evaluation metrics table (accuracy, precision, recall, F1, top-3/5,
inference speed), bar charts across algorithms, and per-algorithm confusion
matrices on the held-out test split.

Each mode's labels come from its own `models/<mode>/label_encoder.pkl`
(alphabet folder names A-Z, number folder names 0-10).

## 6. Deploy (GitHub + Streamlit Community Cloud) - Optional

1. Push this repo to GitHub.
2. Go to https://share.streamlit.io → New app → pick your repo.
3. Set main file path to `app/app.py` → Deploy (requirements.txt is picked up
   automatically; the live-camera tab needs HTTPS, which the cloud provides).
